# DashKit CLI

Command-line tool for installing and managing DashKit agent definitions in your projects.

## Installation

### From GitHub Packages

```bash
npm install -g @sfwd-dashapps/dashkit
```

### From Source

```bash
git clone https://github.com/sfwd-dashapps/dashkit.git
cd dashkit/packages/dashkit-cli
npm install
npm run build
npm link
```

## Quick Start

```bash
# Navigate to your project
cd your-project

# Install DashKit agents
dashkit init --here

# Check installation status
dashkit status

# Update to latest version
dashkit update
```

## Commands

### `dashkit init`

Install agent definitions into your repository.

```bash
# Install in git repository root (finds .git automatically)
dashkit init

# Install in current directory
dashkit init --here

# Force overwrite existing installation
dashkit init --force
```

**What it does:**
- Creates `.claude/agents/` with Claude Code agent definitions
- Creates `.github/agents/` with GitHub Copilot agent definitions
- Creates `dashkit.config.js` configuration file

**Options:**
- `--here` - Install in current directory instead of git root
- `--force` - Overwrite existing files

### `dashkit update`

Update agent definitions to the latest version.

```bash
# Update agents
dashkit update

# Preview changes without modifying files
dashkit update --dry-run
```

**What it does:**
- Overwrites existing agent files with latest versions
- Updates version in `dashkit.config.js`
- Displays summary of updated files

**Options:**
- `--dry-run` - Show what would be updated without making changes

### `dashkit status`

Check installation status and available updates.

```bash
dashkit status
```

**Shows:**
- Installed version
- Available updates
- Which agents are installed (Claude, GitHub)

### `dashkit version`

Display version information.

```bash
dashkit version
```

**Shows:**
- CLI tool version
- Installed framework version (if installed)

## Configuration

After installation, `dashkit.config.js` is created in your project root:

```javascript
// DashKit configuration
// Generated by dashkit v1.0.0
// Documentation: https://github.com/sfwd-dashapps/dashkit

module.exports = {
  "version": "1.0.0",
  "installedAt": "2026-01-28T00:00:00.000Z",
  "agents": {
    "claude": true,
    "github": true
  }
};
```

This file:
- Tracks installed version for update detection
- Is a JavaScript module (supports comments and extensions)
- Should be committed to version control

## Installation Directory Structure

After running `dashkit init`, your project will have:

```
your-project/
├── .claude/
│   └── agents/
│       ├── specification-agent.md
│       ├── research-agent.md
│       └── planning-agent.md
├── .github/
│   └── agents/
│       ├── specification-agent.agent.md
│       ├── research-agent.agent.md
│       └── planning-agent.agent.md
└── dashkit.config.js
```

## Workflow

### Initial Installation

```bash
cd your-project
dashkit init --here
git add .claude .github dashkit.config.js
git commit -m "Install DashKit agents"
```

### Checking for Updates

```bash
dashkit status
# Output: ⚠ Update available: 1.1.0
```

### Updating

```bash
# Preview changes
dashkit update --dry-run

# Apply update
dashkit update
git diff  # Review changes
git commit -am "Update DashKit agents to v1.1.0"
```

## Error Handling

The CLI provides clear error messages:

- **Not in git repository**: Use `--here` flag or navigate to a git repository
- **Already installed**: Use `--force` to overwrite or `dashkit update` to upgrade
- **Not installed**: Run `dashkit init --here` first
- **Permission denied**: Check file permissions or run with appropriate privileges

## Requirements

- **Node.js**: 18.0.0 or higher
- **Git**: Optional (required without `--here` flag)

## Exit Codes

- `0` - Success
- `1` - Error (check error message for details)

## Troubleshooting

### Installation fails with "already installed"

```bash
# Use --force to overwrite
dashkit init --force

# Or update instead
dashkit update
```

### Can't find git repository

```bash
# Use --here to install in current directory
dashkit init --here
```

### Permission errors

```bash
# Check directory permissions
ls -la .claude .github

# Ensure you have write access
chmod u+w .claude .github
```

### Config file is corrupted

```bash
# Delete and reinstall
rm dashkit.config.js
dashkit init --force
```
