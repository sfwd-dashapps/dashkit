# Contributing to Dashkit

Contributing to Dashkit is easy.

## Did you find a bug?
* Open a [Github Issue](https://github.com/sfwd-dashapps/dashkit/issues) and clearly state the purpose of the contribution, with a summary title and generous description. Include brief code samples, an executable test, or documentation of the issue or feature.


## Did you write a patch or new feature?
* Open a [Pull Request](https://github.com/sfwd-dashapps/dashkit/pulls). Target the `dev` branch. 
* Fill out each of the sections fully.
* To be considered, all Pull Requests need
* * A descriptive title
* * A detailed description of the contribution
* * One or more tests that demonstrate expected behavior
